## 👋 About

I build **agents that do the work**, **APIs that hold up in production**, and **ML that makes it out of the notebook**.

- 🤖 Agentic AI systems and RAG pipelines, built on Python backends
- ⚙️ Async FastAPI, JWT and RBAC, Redis, Celery, Alembic, Docker
- 🚀 Models shipped as real services, not notebooks: Streamlit and FastAPI, containerised
- 💬 Ask me about agents, API design, or getting a model from notebook to deployed
